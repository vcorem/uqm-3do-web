Third-party notices for urquanmasters.org
============================================================================

This file lists the third-party software in the games on urquanmasters.org:
the code that is compiled into the game builds or that the site sends with
them. For each part it gives the version, the builds that use it, the
copyright lines, the license (SPDX identifier) and the license text. Tools
that only make the builds (compilers, bundlers, build scripts) are not in
this list.

The Ur-Quan Masters game code is free software under the GNU General Public
License (GPL). See COPYING.txt on each UQM game page and the source
repository:
    https://github.com/vcorem/uqm-3do-web

The game content (graphics, music, sound, speech and text) has its own
licenses: see COPYING.txt, content-licenses.txt and melee-credits.txt on the
game pages. Cosmo Clash is based on
https://github.com/ohanegby/cosmoclash-web and keeps its models, textures
and sounds (see cosmoclash/ in the source repository).

Date:       2026-10-23
Generator:  scripts/make-third-party-notices.py in the source repository


Builds
----------------------------------------------------------------------------
/original/       The Ur-Quan Masters, C engine
/original-rust/  The Ur-Quan Masters, Rust engine (port of the C engine)
/hd/             UQM HD (UQM-MegaMod 0.8.5 source), C engine
/hd-rust/        UQM HD, Rust engine (port of the HD C engine)
/melee/          Melee Remastered: the /hd/ build with the Melee page
/melee-rust/     Melee Remastered: the /hd-rust/ build with the Melee page
/cosmoclash/     Cosmo Clash
