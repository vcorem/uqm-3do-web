01 / Start here

A ship with one extra chair.

Seven years after the Sa-Matra’s defeat, the Wayfarer surveys settlements beyond the old Hierarchy frontier. An abandoned planetary shield requests a passenger berth. The caller is new, alive, and difficult to fit into a reconstruction system that already knows how every request should be answered.

Original victories remain meaningful. The new story grows from the unfinished work of liberation, with humor, material constraints and people whose interests do not neatly agree.

What the player gets

Star chart, travel and resupply, readable transmissions, portraits, musical themes, evidence and quest journal, complete conversation log, automatic saves with backup recovery, import/export, surface expeditions, space battles and three fully authored endings.

Reading is untimed. Travel and certain decisions advance days. Resource exhaustion, retreat and defeat have recovery paths. Known open signals are listed in the journal.

Plot architecture — major spoilers

The reconstruction network creates provisional Afterlight minds to forecast decisions, then discards versions that refuse. Sera authorized predictive assent without understanding the lives being erased. Discovery does not make her previous authority legitimate or her relief work worthless.

The pluralist accord requires actual clocks, public witnesses, independent capacity and a prepared harbor. The mandate saves people through centralized authority with selectable safeguards. Partition preserves autonomy while reducing the Reach’s shared capacity. Each ending has consequences and conditional personal epilogues. The game does not reduce this to a universal morality score.

The story bible records the full four-act outline, faction motives, reveal timing, clue routes, canonical boundaries and unresolved mysteries.

03 / Implementation

Authored data, deterministic rules, real encounters.

LayerImplementationContract
Narrativecampaign/content/campaign.jsonScenes, choices, requirements, resources, discoveries, world events and endings. No runtime story generation.
Campaign statecampaign/src/state.mjsImmutable atomic actions, strict save validation, one-time rewards, explicit pending encounters and matching receipts.
Presentationapp.mjs, HTML and CSSResponsive illustrated interface, full transcripts, keyboard choices, accessible buttons and larger text.
Surfacelander.mjs, CanvasSeeded terrain, fixed-step acceleration and braking, hazards, battery, ore, three physical scans and a return to the pad.
CombatOriginal UQM Rust → WebAssemblyNative hulls, weapons, specials, AI, collision and crew. An isolated iframe reports a real victory, defeat or withdrawal.
MusicLocal Ogg + Web Audio15 original cues with crossfades, user-gesture activation, bounded cache and a music toggle.
Buildscripts/build-afterlight.shClean portable output, SHA-256 file manifest, no stale build assets. Refuses to replace unrelated output directories.

The campaign shell and new surface game are JavaScript. Space combat uses the existing Rust translation and preserves original UQM pixel-art ships and sound effects. This is not a claim that the entire campaign is Rust, that all ships were redrawn, or that the original lander was ported into this new interface.

Hosting

Serve .tools/afterlight-dist/ over HTTPS with Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Embedder-Policy: require-corp. Serve .mjs as JavaScript and .wasm as WebAssembly. The included Rust server already provides the necessary behavior. Localhost is sufficient for local play. No campaign server, AI subscription, telemetry or remote media service is required. For a downloadable release from a clean committed checkout, run bash scripts/package-afterlight-release.sh. The resulting ZIP includes an exact corresponding source archive, revision, file hashes and hosting instructions.

Use a dedicated path or origin for preview. The existing Original/HD launchers and multiplayer system remain separate. Deployment and a merge to main have not been requested.

Provenance and editability

The new illustrations were generated from text with OpenAI’s built-in image tool. campaign/assets/art-manifest.json records generation mode, art direction, briefs, dimensions and hashes. The music uses explicitly authored motifs and arrangements rendered by campaign/tools/compose.py; it contains no sampled recordings. The editable scores and generator are delivered alongside the recordings.

New code and writing are GPL-2.0-or-later. New generated art and synthesized music are CC BY-SA 4.0 to the extent rights are held. Existing UQM code and assets keep their existing terms. See campaign/CREDITS.html. No recorded voice performances are included.

Keep the story schema and state tests together. For any plot edit, validate references and replay affected ending and recovery routes. Native Rust hooks are documented and preserved in campaign/native-hooks.patch; apply them to a staging translation rather than overwriting the working engine.

Before a public release

Invite independent players to complete several routes without a guide. Review pacing, humor, emotional payoffs, music fatigue, difficulty and accessibility. Test Safari and Firefox and longer sessions. Mobile reading and surface controls work; native battles still need a keyboard.

A test suite establishes functional evidence. It cannot establish that a new story equals or exceeds Star Control II. That judgment belongs to readers and players.
