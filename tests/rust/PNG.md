# PNG Rust differential oracle

`rust/uqm-png/png.rs` owns the UQM/HD decoder and HD writer: PNG transform
selection, SDL formats and surfaces, transparency policy, palettes, row allocation, pixel
layout, stream/error ownership and the alpha-format helper. It exports the
original C ABI. It uses no Rust allocator and works with `no_std`.

`rust/uqm-png/png-guard.c` is an external libpng/stdio binding. It has no SDL
image logic.
Every libpng operation runs inside its own C `setjmp` frame. The C I/O
trampoline calls Rust, receives a byte count, and only then calls `png_error`
when necessary. Consequently no libpng `longjmp` crosses a live Rust frame.
The guard must never be changed to invoke an entire Rust decoder inside one
C jump target, nor may the Rust I/O callback call `png_error` itself.

The independent oracle compiles unchanged Original and HD `png2sdl.c` sources
with renamed exports, linking them beside Rust. Real SDL/libpng headers verify
the Rust ABI. The PNG corpus is generated by libpng's independent writer,
covering valid color/depth combinations, packed pixels, 16-bit stripping,
Adam7 interlacing, palette transparency/partial alpha/multiple transparent
indices, true-color and grayscale transparency, grayscale alpha, one-pixel
images and padded SDL rows.

Comparisons include dimensions, masks, pixel bytes, mapped RGBA, palette RGB,
colorkey, stream consumption/rewind, exact encoded bytes, helper refcounts and
writer stream/surface ownership. Malformed headers/CRCs and truncations verify
error handling; intentional omission of post-IDAT parsing is also retained.
Short-output failures exercise the C trampoline after Rust returns.

Three legacy defects receive defined behavior rather than unsafe equivalence:

- C leaves palette alpha uninitialized. Rust sets opaque alpha 255. The oracle
  compares RGB and indices exactly and normalizes only legacy palette alpha
  before comparing mapped pixels. Nonpalette pixel alpha remains exact.
- C ignores short reads/writes. Rust rejects them through the C error guard.
  Truncations must fail and rewind; short writes must fail and release the
  input surface reference according to the original writer ownership rule.
- C may close a null writer stream when `freedst` is set. Rust skips that null
  close. HD's other unusual ownership rule—freeing the input surface on writer
  failure—is preserved. The writer still omits palette `tRNS`, as in HD.

Run from the repository root:

```sh
npm run test:rust:png
bash tests/rust/build-png-test-sdl.sh
bash tests/rust/test-png.sh --native
```

`--all` runs both targets. Each command runs debug and optimized profiles.
Wasm uses the shared-memory flags, pinned nightly/build-std and Emscripten
3.1.50 used by production. Native C runs with ASan/UBSan; Rust and third-party
libraries are not sanitizer-instrumented. Native currently uses the locally
installed Homebrew libpng headers/library and an isolated static SDL 2.24.2
build from Emscripten's cached source. `SDL2_CONFIG` and `LIBPNG_CONFIG` can
select another actual SDL2/libpng installation through their standard
configuration scripts. Homebrew's `sdl2` here is SDL2-compat over SDL3 and
stalls in library initialization before `main`; it is deliberately not used.

All four runs pass 1,292,704 comparisons each: 152 valid fixtures, 304 malformed
cases, 636 truncation cases and 14 HD writer cases. Both original C decoder
variants are checked in every run. Artifacts and expected error diagnostics
remain in target/profile subdirectories under ignored `.tools/rust-png-oracle`.
The tests use the same Rust implementation and C codec boundary as both
production engines. They do not establish full browser fidelity or complete
engine migration. The test manifest lives under `tests/rust/png-abi`.
